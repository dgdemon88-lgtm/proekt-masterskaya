Параметр интенсивности дождя A = q₂₀·20ⁿ·(1 + lgP/lg mr)γ
Значения q₂₀, n, mr, γ — по СНиП 2.04.03 (карты/таблицы) для района строительства.
Расчётный расход qr = zmid·A1,2·F / tr(1,2n−0,1)
Метод предельных интенсивностей (СНиП 2.04.03-85 / СП 32.13330). β учитывает свободную ёмкость трубопроводов (0,55–0,85 в зависимости от n).
Подбор диаметра самотёчного коллектора (формула Маннинга, полное сечение)
v = (1/nm)·R2/3·i1/2, R = d/4 (полное сечение); Q = (πd²/4)·v. Минимальная самоочищающая скорость для дождевой сети — 0,7 м/с; максимальная для бетона — 7 м/с.
Объём аккумулирующего резервуара очистных сооружений
W = 10·ha·ψmid·F (м³) — объём наиболее загрязнённого стока, отводимого на очистку (СП 32.13330). На очистку направляется сток слоем ha = 5–10 мм.
