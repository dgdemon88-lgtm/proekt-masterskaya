Снеговая нагрузка · S = 0,7·ce·ct·μ·Sg
μ = 1,0 при α ≤ 30°; линейно снижается до 0 при α = 60°. При перепадах высот, фонарях, парапетах образуются снеговые «мешки» — μ может быть значительно выше (см. СП). Sg — по карте районирования СП РК 2.01-101 (уточняйте по месту строительства).
Ветровая нагрузка (средняя) · wm = w0·k(ze)·c
k(ze) = k10·(z/10)2α: тип A — k10=1,0 (2α=0,30); B — 0,65 (0,40); C — 0,40 (0,50). Пульсационная составляющая здесь оценивается упрощённо (wp = wm·ζν); для ответственных сооружений выполняется полный расчёт по СП.
Сбор нагрузок на элемент
Наименование нагрузки Тип Норм. qн, кПа γf Расч. q = qн·γf
ИТОГО, кПа
qн — нормативная нагрузка, q — расчётная (с коэффициентом надёжности γf). Типовые γf: собственный вес ж/б 1,1; стяжки/утеплитель 1,3; снег 1,4; полезная 1,2–1,3. Линейная нагрузка на балку/прогон = q · b (грузовая ширина).
