# Проектная мастерская

Калькуляторы и инструменты для разделов проектной документации (нормы РК).

**Открыть:** https://dgdemon88-lgtm.github.io/proekt-masterskaya/

Каждый инструмент — отдельный HTML-файл: работает в браузере и офлайн, данные хранятся только в браузере пользователя, на сервер ничего не передаётся.

## Инструменты

- [Электроснабжение](https://dgdemon88-lgtm.github.io/proekt-masterskaya/elec-calculator/) — Расчёт электрических нагрузок
- [Электроосвещение](https://dgdemon88-lgtm.github.io/proekt-masterskaya/light-calculator/) — Светотехнический расчёт (коэф. использования, удельная мощность)
- [Естественное освещение и инсоляция](https://dgdemon88-lgtm.github.io/proekt-masterskaya/daylight-calculator/) — КЕО, площадь световых проёмов, продолжительность инсоляции
- [Лестницы и пандусы](https://dgdemon88-lgtm.github.io/proekt-masterskaya/stairs-calculator/) — Ступени, уклоны, доступность для МГН
- [Молниезащита](https://dgdemon88-lgtm.github.io/proekt-masterskaya/lightning-calculator/) — Зоны защиты стержневого молниеотвода (СО 153)
- [Теплоснабжение и ОВ](https://dgdemon88-lgtm.github.io/proekt-masterskaya/heat-calculator/) — Тепловой калькулятор: нагрузки, сети, ИТП, вентиляция

- [Теплотехника ограждений](https://dgdemon88-lgtm.github.io/proekt-masterskaya/thermal-calculator/) — R по слоям, проверка нормы, точка росы
- [Энергопаспорт здания](https://dgdemon88-lgtm.github.io/proekt-masterskaya/energy-calculator/) — Удельный расход тепла, класс энергоэффективности
- [Нагрузки на конструкции](https://dgdemon88-lgtm.github.io/proekt-masterskaya/kr-calculator/) — Снеговые, ветровые, сбор нагрузок

- [Охрана окружающей среды](https://dgdemon88-lgtm.github.io/proekt-masterskaya/eco-calculator/) — Выбросы (ОНД-86), отходы, шум

## Лицензия

Калькулятор «Картограмма земляных масс» включает libredwg-web 0.7.15 (GNU LibreDWG, GPL-3.0) для чтения DWG; исходный код библиотеки: https://github.com/mlightcad/libredwg-web. Репозиторий распространяется на условиях GNU GPL v3 (см. LICENSE).

Нормативные значения в калькуляторах ориентировочные — уточняйте по действующим СП / СН РК и данным изысканий.
