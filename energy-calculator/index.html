Геометрия здания
Климат отопительного периода
ГСОП = (tв − tот) · zот. Значения tот и zот — по строительной климатологии для города строительства.
Ограждающие конструкции — удельная теплозащитная характеристика kоб
Конструкция Площадь A, м² Rпр, м²·°С/Вт n A/R·n, Вт/°С
Σ n·A/R, Вт/°С
kоб = Σ(n·A/Rпр) / Vот. Rпр — приведённое сопротивление теплопередаче конструкции; n — коэффициент, учитывающий положение (для наружных ограждений n = 1; для перекрытий над подвалом/проездами n = 0,6…0,9). Площади — по наружному обмеру.
Удельная вентиляционная характеристика kвент
Теплопоступления (снижают расход)
kвент = 0,28·c·nв·βv·ρв·(1 − kэф), c = 1 кДж/(кг·°С). kбыт = qбыт·Aж / (Vот·(tв − tот)). Типовые qбыт: жилые 10–17, общественные по расчёту.
