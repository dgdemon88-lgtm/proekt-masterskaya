Стальная балка на изгиб (шарнирно опёртая, равномерная нагрузка)
M = q·L²/8; требуемый момент сопротивления Wтр = M/(Ry·γc). Проверка прочности σ = M/W ≤ Ry·γc и прогиба f = 5qнL⁴/(384EI) ≤ [f].
Стальная колонна на центральное сжатие (устойчивость)
Гибкость λ = μl/imin; φ — коэф. продольного изгиба (по λ, СП 16.13330). Условие: N ≤ φ·A·Ry·γc. Рекомендуется λ ≤ 120 для колонн.
Ж/б балка прямоугольного сечения (изгиб, одиночная арматура)
αm = M/(Rb·b·h₀²); ξ = 1 − √(1 − 2αm); площадь арматуры As = ξ·Rb·b·h₀/Rs. Проверка ξ ≤ ξR (иначе требуется сжатая арматура или увеличение сечения).
Подбор площади подошвы фундамента
Упрощённо: Aтр = N/(R₀ − γср·d); давление под подошвой p = N/A + γср·d ≤ R₀. R₀ — предварительное (табличное) расчётное сопротивление; для проекта уточняется по формуле СП 22.13330 с учётом характеристик грунта (c, φ, γ).
