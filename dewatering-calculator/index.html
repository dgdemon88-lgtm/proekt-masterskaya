Приток воды к котловану (совершенная выработка, метод большого колодца)
Приведённый радиус котлована r₀ = √(F/π). Радиус влияния (Кусакин): безнапорный R = 2S√(kH), напорный R = 10S√k. Приток: безнапорный Q = π·k·(2H−S)·S / ln((R+r₀)/r₀); напорный Q = 2π·k·m·S / ln((R+r₀)/r₀). Оставьте R=0 для автоподбора.
Подбор водоотливных насосов
Расчётная подача = Q·kзап. Число рабочих насосов = расчётная подача / производительность одного (плюс резервный). Мощность на валу N = ρ·g·Q·Hн/η.
