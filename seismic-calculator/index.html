Веса, сосредоточенные на уровнях этажей
Qk — вес, отнесённый к уровню k: собственный вес конструкций + длительная часть временных нагрузок (по норме учитывается с понижающими коэффициентами: снег 0,5; полезная 0,5 для жилых/общественных, 0,8 для складов).

Метод — линейно-спектральный по первой форме колебаний (СП РК 2.03-30-2017, СНиП РК 2.03-30). Форма принята линейной: Xk = zk/H, что допустимо для регулярных зданий с равномерным распределением масс и жёсткостей. При нерегулярности по высоте, гибком нижнем этаже, значительном кручении или высоте свыше нормируемой требуется расчёт по нескольким формам колебаний (модальный анализ). Вертикальная сейсмическая составляющая здесь не определяется.
