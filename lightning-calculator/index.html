Одиночный стержневой молниеотвод (СО 153-34.21.122)
Зона защиты — конус: h₀ = kh·h (вершина), r₀ = kr·h (радиус у земли), rx = r₀·(h₀ − hx)/h₀ (радиус на высоте объекта). Коэффициенты по надёжности (h ≤ 30 м).
Подбор высоты молниеотвода по защищаемому объекту
Из rx = r₀·(h₀ − hx)/h₀ при r₀ = kr·h, h₀ = kh·h получаем требуемую высоту молниеотвода h.
Двойной стержневой молниеотвод (равной высоты)
При L ≤ Lc провис зоны в середине отсутствует (hc = h₀). При Lc < L ≤ Lmax: hc = h₀·(Lmax − L)/(Lmax − Lc). При L > Lmax молниеотводы работают как одиночные.
