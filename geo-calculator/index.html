Изгиб плиты. Армирование (полосовой метод)
—
Расчётная схема: плита на упругом основании, нагрузка = давление грунта q = pср (равномерно). Полоса шир. 1 м: Mx = α · q · lx² My = α · q · ly² (α = 1/8 для неразрезной) h₀ = h − a₀ As = M / (Rs · ξ · h₀), ξ = 0.9 As,min = μmin · b · h₀, μmin = 0.10%
Продавливание колонной (СП РК 52-101-2003)
—
Расчётный контур — на расстоянии h₀/2 от граней колонны: u₀ = 2·(a + b + 2·h₀) F = Ncol − pср·(a+h₀)·(b+h₀) (местная нагрузка) Fb = γb · Rbt · u₀ · h₀ · (1 + φn) Условие: F ≤ Fb

—
Критическое сечение — у грани колонны: cx = (b − bc)/2, cy = (l − lc)/2 mx = p_I · cx²/2 (кН·м на 1 м ширины в y-направлении) my = p_II · cy²/2 (кН·м на 1 м ширины в x-направлении) p_I = p_avg + (p_max−p_avg)·(l/2−lc/2)/(l/2) — ср. давл. на консоли cx p_II = p_avg (для нагрузки без My — симметрично) h₀ = h − a₀, As = m / (Rs · 0.9 · h₀)
Продавливание колонной (СП РК 52-101-2003)
—
Контур продавливания (h₀/2 от грани колонны): u₀ = 2·(bc + lc + 2·h₀) F = N − p_avg·(bc+h₀)·(lc+h₀) Fb = γb·Rbt·u₀·h₀·(1+φn) Условие: F ≤ Fb Проверка минимальной высоты: h ≥ cx/2 + a₀ (пирамида продавливания ≥ 45°)

Момент у грани колонны (жёсткий ростверк): M_x = Σ N_i·(xi − bc/2) для xi > bc/2 [кН·м итого] M_y = Σ N_i·(yi − lc/2) для yi > lc/2 m_x = M_x / l_cap, m_y = M_y / b_cap [кН·м/м] As = m / (Rs · 0.9 · h₀)
Продавливание ростверка
—
От колонны: u₀ = 2(bc+lc+2h₀); F_col = N − Σ N_пир (сваи внутри пир.) Fb = Rbt·u₀·h₀·(1+φn) От одиночной сваи (снизу вверх): u₀_p = периметр сечения сваи + 4h₀·tan45° = 4(d+h₀) кв. или π(d+h₀) кр. F_p = N_pile_max; Fb_p = Rbt·u₀_p·h₀
Осадка группы свай — метод условного фундамента (СП РК 5.01-102-2013, п.7.4)
—
α = φ_ср / 4 — угол рассеивания нагрузки Размеры условного фундамента у острия свай: B_eq = [(nx−1)·sx + dp] + 2·Lp·tan(α) L_eq = [(ny−1)·sy + dp] + 2·Lp·tan(α) Давление у острия: p_eq = (N_tot + G_ростверка + G_свай + G_грунта) / (B_eq·L_eq) Проверка: p_eq ≤ R_острие (R по СП РК 5.01-101-2013 для глубины острия)
