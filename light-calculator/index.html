Нормирование и коэффициенты
Светильник / источник света
Число светильников N = E·S·Kз·z / (Φ·η), округляется вверх. Индекс помещения i = A·B / (Hр·(A+B)), где Hр = H − hр − hс. η зависит от i, типа светильника и коэффициентов отражения — уточняется по светотехническим таблицам/каталогу (см. подсказку у поля η).
Оценка по методу удельной мощности
Метод удельной мощности — быстрая оценка/проверка: Pобщ = w · S. Ориентировочные w для LED-освещения: офисы 8–12, торговые 12–18, производство 10–20, склады 4–8, коридоры 3–5 Вт/м². Для точного расчёта используйте метод коэффициента использования.
