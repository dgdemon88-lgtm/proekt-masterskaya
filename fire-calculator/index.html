Характер пожарной опасности помещения
Для категории В — площадь участка размещения (принимается не менее 10 м²).
ΔP > 5 кПа подтверждает категорию А/Б. При ΔP ≤ 5 кПа — категория В по нагрузке.
Пожарная нагрузка (для категории В)
Материал Из справочника Масса G, кг Qн, МДж/кг Q = G·Qн, МДж
Пожарная нагрузка Q, МДж
Категория В по удельной пожарной нагрузке g = Q/S: В1 > 2200; В2 = 1401…2200; В3 = 181…1400; В4 = 1…180 МДж/м². Категории А/Б определяются по избыточному давлению взрыва ΔP > 5 кПа (требует отдельного расчёта). Основание — СН РК / СП 12.13130.
Расчётное время эвакуации (участковая модель)
Обычно принимается по назначению здания (часто 6 мин).
Участок пути Тип Длина l, м Ширина δ, м Людей N D, м²/м² v, м/мин q, м/мин t, мин
Расчётное время эвакуации tр, мин
N задаётся только на первом участке (людской поток идёт последовательно). На следующих участках интенсивность переносится по ширине: qi = qi-1·δi-1/δi. Если q превышает максимум для данного типа пути — образуется скопление (⚠), движение при максимальной плотности. Значения v и q — по методике определения расчётных величин пожарного риска (табл. зависимости v–D). Тип «дверной проём» — длина ≈ 0.
Требуемая ширина эвакуационных выходов
Требуемая ширина одного выхода = N / (число выходов · норма). Минимальная ширина эвакуационного выхода — 0,8 м; при числе эвакуирующихся более 50 чел через выход — не менее 1,2 м. Основание — СН РК 2.02 / СП 1.13130.
