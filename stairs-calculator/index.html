Расчёт лестницы
Число ступеней n = H/h (округляется, подступёнок пересчитывается). Формула удобства: 2h + b = 600…640 мм; формула безопасности h + b ≈ 450 мм. Уклон = h/b. Число ступеней в марше рекомендуется 3–18.
Расчёт пандуса для маломобильных групп населения (МГН)
Для МГН уклон пандуса ≤ 8% (1:12), предпочтительно 5%. Максимальная высота одного марша — 0,8 м, далее горизонтальная площадка длиной не менее 1,5 м. Ширина пандуса — не менее 1,0 м (при одностороннем движении). Основание — СП 59.13330 / СН РК 3.06-01 (доступность для МГН).
